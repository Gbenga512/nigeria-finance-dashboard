# NG Finance Pro Dashboard 🇳🇬📊

A real-time Nigerian financial intelligence dashboard built with Python and Streamlit.

## Features

- USD/NGN exchange tracking
- Bitcoin monitoring
- Commodity price analysis
- AI-powered market insights
- Risk monitoring dashboard
- Financial data visualization

## Technologies Used

- Python
- Streamlit
- Pandas
- Plotly
- GitHub
